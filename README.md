# Myne

A lightweight web project using standalone React, ReactDOM, and Babel loaded via standard `<script>` tags for offline/browser-side compilation.

## Setup & Running

1. Clone or download this repository.
2.inside that folder Run:
```
npm install
```
and : 
```
npm start
```
